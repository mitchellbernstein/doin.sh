# AI and plan policy

User-supplied AI is free: local models, API keys, supported ChatGPT/Codex provider access, approved local MCP tool loops, and local voice. doin adds no subscription requirement. Provider access, usage charges, model capabilities and local hardware remain supplied by the user.

doinMORE remains $4.99/month or $49.99/year for managed sync and hosted integrations. doinWITH remains $99/user/year for collaboration, scoped permissions, assignees and commercial self-hosting. Personal self-hosting remains free under the personal-use license. Managed sync across terminal and Apple apps is paid; native-app availability, App Store purchasing and live billing are separate delivery states.

The previous paid-AI checkpoint was never released. Remove its receipt service, client gates, separate AI account and test-only signing scaffolding rather than retaining dormant paywall code. Preserve session/workspace race checks, explicit tool approval, proposal source checks and server authorization for hosted integrations. This applies the Laziness Protocol through deletion.

Failure census: guest or unpaid users accidentally require sign-in; a local provider call requests an entitlement; guest proposals fail because nil account identity differs from an empty string; stale proposals apply after account/workspace changes; free AI bypasses hosted integration billing; tests retain paid fixtures and hide a gate. Verify actual guest provider/tool flows and no-account credential directories, with reproducible E2E artifacts.

Throughput checkpoint: root owns terminal/backend cleanup, pricing copy and existing native E2E; iOS agent owns narrow Apple AI gates and account/workspace guards. Build/test lanes run serially. No live billing or external-provider behavior changes are required for this policy reversal.
