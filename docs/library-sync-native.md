# Whole-library native sync

Failure census and E2E fixtures were written before implementation. Required behaviors: stable folder IDs across devices, independent Markdown/CAS per node, explicit initial push/pull, first-link divergent data refusal, metadata revisions, concurrent moves/renames, malformed/cyclic/disconnected trees, private baseline state, per-folder conflict copies, changed root aliases, external editor changes during network I/O, partial sync/retry, missing local nodes and remote tombstones, expired access and legacy root endpoint isolation.

The native bridge uses the existing authenticated HTTP transport. It sends no account ID, credentials in metadata, implicit deletion or forced overwrite. Local root identity maps to cloud `root`; descendant identities are the portable 32-hex IDs. Library metadata and document baselines are separate. A new client uses `/v1/folders` and per-folder documents while legacy clients continue root `/v1/document`. Incoming structural changes preserve document bytes and selection follows stable IDs. Both metadata snapshots and affected Markdown are retained on conflict.

Planned reproducible E2E: `python3 tests/library_sync_e2e.py`; artifact `artifacts/library-sync/result.json` and `server-tree.json`. Runtime result is pending the shared build lane. Provider contracts follow [D1 transactional batches](https://developers.cloudflare.com/d1/worker-api/d1-database/) and [composite foreign-key enforcement](https://developers.cloudflare.com/d1/sql-api/foreign-keys/).

Explicit resolution census: two conflicting folder documents, unchanged documents, force upload losing current CAS after full backup, external edits before commit. `sync push --force` resolves document conflicts across the library using current remote revisions; `sync pull --accept-remote` chooses cloud bytes. Both keep full local/cloud snapshots first. Metadata conflicts and omissions stay blocked; automatic sync never forces.

Verification receipt: parent ran the latest native library fixture successfully, including explicit document resolution, deep hierarchy, external-editor/provider races and portable canonical root checks. `artifacts/library-sync/result.json` records the real CLI commands and HTTP operations. No actual OS jobs were installed.
